# AI SDK Agents demo videos

Screen recordings of [AI SDK Agents](https://aisdkagents.com) demos, for social posts. 65 clips: 41 AI Components and 24 patterns.

## For bots

Read [`manifest.json`](https://raw.githubusercontent.com/nolly-studio/ai-sdk-agents-demo-videos/main/manifest.json). It lists each demo once, with its caption, the page to link and the raw URL of its mp4, so pick from `clips` instead of listing folders. Some AI Components also have an older dark version next to the light one (`<name>.mp4`); the manifest leaves those out so a demo is not posted twice.

Each clip has: `id`, `kind` (`ai-component` or `pattern`), `title`, `caption` (one line, no closing period), `page`, `video`, `thumbnail`, `theme`, `seconds` and `recorded`.

Generated 2026-11-17 from the shadcn-ui repo (`pnpm --filter=v4 reel:manifest`). Do not edit this file or the manifest by hand.
